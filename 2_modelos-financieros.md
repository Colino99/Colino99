# Modelos financieros

Modelos construidos desde cero, con hipótesis explicadas. Cada modelo va en su propia subcarpeta con el Excel y un README breve.

## Cómo documentar cada modelo

```
modelos-financieros/
└── 2026-xx-nombre-del-modelo/
    ├── modelo.xlsx
    └── README.md   ← qué es, hipótesis clave, resultado, qué aprendí
```

Plantilla de README para cada modelo:

> **Empresa / caso:** …
> **Tipo:** tres estados / DCF / LBO
> **Hipótesis clave:** crecimiento, márgenes, capex, working capital, deuda…
> **Resultado:** valoración / TIR / múltiplo de salida…
> **Qué aprendí:** …
