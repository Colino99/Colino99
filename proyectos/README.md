## Ideas para empezar

- **Analizador de cuentas anuales:** subes el balance y la cuenta de resultados de una empresa y calcula ratios, conversión de caja y señales de alerta.
- **Calculadora LBO interactiva:** página HTML donde mueves hipótesis (precio, deuda, crecimiento) y ves la TIR y el múltiplo al instante.
- **Seguimiento de cartera:** registro de inversiones con rentabilidad y comparación con un índice.
- **Automatizaciones Excel/Python:** scripts para tareas financieras habituales (consolidar ficheros, conciliar, generar informes).
